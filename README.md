# OneDayOnly Redesign

A modern redesign of [OneDayOnly.co.za](https://www.onedayonly.co.za) — South Africa's biggest daily deals site. Full frontend demo with 130+ pages.

**Live Demo:** [onedayonly-redesign.vercel.app](https://onedayonly-redesign.vercel.app)

## Features

- 130+ fully designed pages
- Dark mode support
- Animated page transitions and micro-interactions
- Product cart and wishlist
- Search with filtering
- Responsive mobile-first design

## Tech Stack

- **Framework:** Next.js 16, React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **State:** Zustand

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
